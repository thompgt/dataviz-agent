# dataviz-agent

Natural language in, an accessible **validated** chart out.

Ask a question in plain English against a CSV — or point it at data you already
have — and get back a chart whose colors have been *computed* rather than
guessed: colorblind-separation, contrast, lightness and chroma are all checked
before anything renders.

> **Status:** under active construction. See [AGENT.md](AGENT.md) for the agent
> contract and [docs/](docs/) for the design notes.
